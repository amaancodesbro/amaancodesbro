## Featured Engineering Projects

### 01 — Barter | Full-Stack MERN Marketplace

A peer-to-peer item-exchange platform that enables users to publish listings, discover available items, and initiate structured swap requests.

**Technical implementation**
- React and JavaScript for the client-side application.
- Node.js and Express.js for backend application logic and REST API endpoints.
- MongoDB Atlas and Mongoose for persistent data storage and schema-based data modelling.
- JSON Web Tokens (JWT) for authentication and bcryptjs for password hashing.
- Cloudinary for image hosting and integration with listing workflows.
- Swap-request workflows supporting incoming and outgoing requests, acceptance, and rejection.
- Deployment using Render.

**Project links:** [Live Application](https://barter-4oy8.onrender.com) · [Source Code](https://github.com/amaancodesbro/Barter)

### 02 — NOVA AI | Python Voice Assistant

A Python-based desktop assistant that combines voice interaction, AI-generated responses, speech synthesis, and external API integrations.

**Technical implementation**
- Python-based application logic and voice-driven interaction.
- SpeechRecognition for converting spoken input into text.
- pyttsx3 for text-to-speech output.
- Google Gemini API integration for AI-powered responses.
- OpenWeather API integration for weather information.
- Utility workflows including web search, application control, note-taking, and screenshot capture.

**Project link:** [Source Code](https://github.com/amaancodesbro/NOVA-AI)
